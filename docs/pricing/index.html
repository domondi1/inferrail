Card

$10 for 10,000 credits. One credit = $0.001. A person completes Stripe Checkout after creating a workspace key. No subscription or automatic replenishment.

USDC

$1 for 1,000 credits over x402 on Base. Your authorized wallet purchases the credits; subsequent Web Read requests use the API key.

A page costs 2 credits. Insufficient credit refuses the read before delivery. Web Read credits have no free allowance. Hosted’s free runs below are inference governance, not page reads. Pay for delivery. Understand the path.

Native evidence APIs charge only on a delivered result. Wallet-based batches are all-or-nothing; the API-key SDK charges each successfully delivered page separately. Matching Web Read retries can recover the paid result within 10 minutes. Delivery and recovery conditions .
