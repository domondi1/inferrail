Package Check

Review up to 20 package versions against OSV.dev for $0.002 per delivered check.

For dependency review, CI checks and remediation research. Receive advisory IDs, CVE aliases, summaries, severity and fixed versions where the source provides them. Supported ecosystems include npm, PyPI, Go, crates.io, Maven, NuGet, RubyGems and Packagist.

Copy-paste example 
curl -i -X POST https://inferrail-cost-gateway.onrender.com/pkg/v1/check \
  -H 'Content-Type: application/json' \
  -d '{"packages":[{"ecosystem":"npm","name":"lodash","version":"4.17.20"}],"request_id":"dependency-review-1"}'
# Unpaid: HTTP 402 with x402 Base and MPP Tempo offers.

Read the result: results[].vulns contains the advisories; check complete , details_truncated and checked_at . A result with no matching advisory is a delivered check, not proof that a package is secure. An OSV outage is uncharged. This is not a full code audit.

Domain Check

One domain’s infrastructure, $0.002 per delivered lookup.

For domain investigations, email configuration reviews and vendor research. Receive DNS records, SPF and DMARC policy, plus available RDAP registrar, status, creation and expiry information.

Copy-paste example 
curl -i -X POST https://inferrail-cost-gateway.onrender.com/domain/v1/lookup \
  -H 'Content-Type: application/json' \
  -d '{"domain":"example.com","request_id":"domain-review-1"}'
# Unpaid: HTTP 402. No lookup is purchased.

Read the result: inspect dns , email , registration_status and registration . Fields and registration coverage vary. A resolver outage is uncharged; missing or unsupported RDAP data may accompany a delivered DNS result. A domain lookup is evidence, not a trustworthiness verdict.

x402 Finder

Find paid APIs for a task. $0.002 per delivered answer; no match is free.

Receive up to five resources with URL, method, description, available price, payment network, recipient and example input. Use these details to evaluate the next tool before purchasing from that provider.

Copy-paste example 
curl -i -X POST https://inferrail-cost-gateway.onrender.com/find/v1/find \
  -H 'Content-Type: application/json' \
  -d '{"need":"read a public web page as markdown","request_id":"find-reader-1"}'
# Unpaid: HTTP 402. Third-party calls are not executed by Finder.

How ranking works: a text-relevance score is weighted by the number of unique paying wallets reported over 30 days. The selected CDP Bazaar catalog requires at least two reported payers. Refresh targets six hours; inspect catalog_as_of and catalog_size in each response. Coverage is selective and the data may lag.

Finder does not call, certify or guarantee third-party services. Their prices and terms remain their own. A missing catalog or no match is uncharged. Complete contract .

Purchase and retry terms.

These three live wallet endpoints accept x402 on Base and MPP on Tempo. Payment settles after a result is produced; errors are uncharged. Recover a paid answer within 10 minutes using the same complete request, request ID and payer. Use a new request ID for fresh evidence.

Package Check and Domain Check also accept your prepaid workspace key at POST /pkg/credits/v1/check and POST /domain/credits/v1/lookup. Use the same JSON input and Authorization: Bearer <key>. Each delivery costs 2 credits ($0.002); an insufficient balance returns 402 without a check. Published SDK 0.3.0 credit mode remains Web Read-only; use direct HTTP for these two. Finder is wallet-only.
