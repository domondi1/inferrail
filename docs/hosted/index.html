250 runs a month free. Then $0.001 per run.

Unit

A governed run is a distinct work ID per UTC calendar month. It is billable only if at least one call is answered by the provider. Calls without a work ID count as separate runs.

Allowance & credits

250 qualifying runs per workspace per month free; then one credit ($0.001) per run. Credits: $10 for 10,000 by card, or $1 for 1,000 over x402 on Base. A person completes card checkout. No subscription, automatic replenishment or overage bill.

Separate provider costs

Inference is billed by your model provider on your own key. The free allowance covers governance only; it does not include inference or Web Read.

Experimental pricing. Previously purchased credits retain their terms. A current sales cap may refuse a top-up without charging. Live pricing and purchase status .

Point your OpenAI SDK at https://inferrail-cost-gateway.onrender.com/hosted/v1 , or your Anthropic SDK at https://inferrail-cost-gateway.onrender.com/hosted . Authenticate with the workspace key, send your provider key in X-Provider-Api-Key , and add a stable X-Inferrail-Attribute-Work-Id and X-Inferrail-Budget-Usd .

The first ceiling for a work ID is retained. Calls without a ceiling are metered but uncapped. A call refused by its run budget does not reach the provider. Pre-call reservation controls admission; provider usage can exceed an estimate, and such an overrun is recorded. Only routed calls are governed. Current deployment uses a single instance and shared workspace ledger.

Know what the hosted process handles.

Your provider key travels with the request and is held in memory for forwarding; it is not stored in receipts. Receipts contain costs and identifiers, without prompt or response bodies. The hosted process handles inference content in transit; your provider sees it. Caller tags are stored as supplied.

For a gateway you operate yourself, use the open-source spending controls . For public source retrieval instead of inference, start with Web Read .
