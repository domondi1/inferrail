Try with your own API keyUse your OpenAI or Anthropic key for a real request.

Your key is held in this server's memory only, for at most 4 hours. It is never written to disk, logged, or put in a receipt. Real requests are billed to your provider account.

How key handling works

Your key is used only to send your own requests to the provider you gave it for. Inferrail never uses it for anything else. The page clears the key from its fields as soon as the server accepts it. This trial, and the key, are deleted automatically within 4 hours of adding it, or right away if you end the trial.

Anyone with this trial's dashboard link can use it, including a key you add, up to the daily cap, until it expires. Would you rather not give a key to any hosted service? Run Inferrail locally instead.

How privacy worksWhat this trial keeps, and what it doesn't.

Every call gets a receipt: provider, model, token counts, cost, timing, and the tags you add. A receipt has no field for a prompt or a response. Tags are stored exactly as you send them, so keep secrets out of them.

In demo mode nothing leaves this service. With your own key, this hosted process holds the key in memory and handles your traffic, and your request goes to OpenAI or Anthropic as usual, so your provider still sees it. Inferrail's receipts do not contain it.

Each trial is isolated from every other trial. Demo data is deleted within 24 hours. Once you add a key, the trial and the key are deleted within 4 hours. How this trial works
