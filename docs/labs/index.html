Inferrail Labs

Experiments in economics for autonomous agents. They are hosted, paid per call over x402, and run on Base Sepolia testnet only.

Labs · testnet

Work Economics

An agent sends payload-free cost metadata for one unit of AI work, and gets back a normalized cost analysis plus a receipt it can reconcile. No subscription, no Inferrail account.

  • Paid per call over x402
  • Base Sepolia testnet only
  • No prompt or response content needed
See Work Economics
Labs · testnet

Economic Authority

Several agents coordinate a shared spending boundary that the caller declares, paid per session over x402.

  • Paid per session over x402
  • Base Sepolia testnet only
  • Recorded within Inferrail's own service only
See Economic Authority

What these are not

Neither experiment controls external wallets, providers, or network spending. Economic Authority is cooperative coordination, not real-world spend enforcement. For the product that measures what your AI work costs today, start here.
